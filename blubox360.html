BluBox 360

An Xbox 360 emulation project for ARM64 Android handhelds, focused on modern Snapdragon and Adreno devices. The AYN Thor Pro is the main development target.

Built for handheld play

BluBox combines a Xenia-derived core with an Android frontend, game library tools, controller tuning, profiles, saves, achievements and thermal protection.

Performance modes

Performance, Balanced, HD, HD+ and custom renderer options, with native through 7x internal resolution choices.

Smart Heat Guard

Thermal status and thermal headroom checks help apply cooler settings when a device approaches throttling.

Controller tuning

Profiles, macros, stick curves, deadzones, trigger controls, vibration and precision aiming options.

Game library

ISO, ZAR and extracted default.xex support from internal storage or microSD, with folder scanning and cover artwork.

Profiles and saves

Up to eight local profiles, profile photos, automatic save data, local achievements and gamerscore.

AYN Thor display

Lower-screen FPS, temperature, battery, charging, active profile, achievement progress and unlock information.

Latest release

BluBox 360 0.16.3 public alpha

This release adds manual update checks, Smart Heat Guard, thermal-aware frame limits and permanent signing for normal in-place updates from recent versions.

  • Settings > App > Check for updates
  • Automatic and manual update checks
  • Thermal-aware Low Heat Mode
  • 60 FPS target can reduce to a 30 FPS safety ceiling under thermal pressure
  • Severe-heat shutdown protection remains active
  • Fable II keeps a 24 FPS safety ceiling

Compatibility

BluBox is an alpha project. Compatibility varies by title, device, driver and settings.

Test ratings

  • Playable
  • In-game
  • Intro
  • Menu

Current limits

  • Game compatibility is incomplete
  • Graphical issues, crashes and slow performance remain possible
  • Player 1 is the active native controller slot in this alpha
  • Custom Vulkan drivers are device-specific
  • Demanding titles can increase device temperature

Use legal game backups you own. Games, Xbox firmware, encryption keys and Microsoft code are not included with BluBox.

Updates and development

BluBox checks the official GitHub Releases feed for newer canonical alpha builds. The project also accepts bug reports, compatibility reports and feature requests through GitHub.
