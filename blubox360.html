BluBox 360

Xbox 360 emulator project for ARM64 Android handhelds

0.16.3 Public Alpha
Android 10+ARM64Vulkan

0.16.3 update

  • Added manual update checks in Settings.
  • Improved Smart Heat Guard using Android thermal status and headroom.
  • Thermal pressure can reduce a 60 FPS target to a 30 FPS safety ceiling.
  • Shader creation is reduced under thermal pressure.
  • Fable II keeps its 24 FPS safety ceiling.
  • Uses the permanent BluBox signing certificate for normal updates.

Main features

BluBox 360 includes an ARM64 Android frontend, Vulkan rendering, game library management, controller profiles, performance presets, local profiles and achievements, lower-screen information for supported AYN Thor setups, mods support, backups and in-app update checks.
